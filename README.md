# PeopleHub HR Portal — React Sample

Run:
npm install
npm run dev

Includes:
- Demo Login
- Dashboard
- Employees with search
- Attendance
- Leave Management
- Payroll
- Performance
- Recruitment
- HR Documents
- Helpdesk
- Travel & Expense
- Responsive desktop/mobile UI

This is a frontend demo using sample data. No real employee, payroll or database connection is included.
